# U3 顺序审查

范围：显式开发计划 U3。依照 AGENTS.md 在主线程顺序审查，未创建子代理；根目录无 Git 仓库，按本轮文件清单检查。

检查视角：ce:review 的正确性、测试、可维护性、项目标准，以及 data-integrity-guardian 的事务/引用/快照/恢复边界。未发现额外项目 AGENTS/CLAUDE 标准或相关 docs/solutions。

## 已落实修正

- 动作依赖与模板同一次提交，失败不留下半个目录或模板；目录只按需持久化。
- 同动作重复项目独立 UUID；复制模板/条目/关联生成新 ID；过期 revision 拒绝覆盖。
- 单次改期为独立业务聚合，不改模板；与已有 session 来源绑定后禁止再改该次安排。
- List 同一行多个按钮改为 borderless，解决改期同时触发开始的实际问题；定向 UI 复测。
- 模板名称键盘在打开选择器前收起，并提供 Done 入口；保存时冻结输入。
- 开始使用同一 actor 的无悬停读写，重复/并发开始返回已有 active ID；实际组不伪装完成。
- 计划目标和目录快照独立；模板编辑/删除、动作编辑/归档不改既有训练。
- 展开组之前检查全库对象上限，防止大模板先分配数百万组再失败。
- 时钟回退/恢复未来开始时刻的记录仍能安全放弃，结束不早于持久化开始时刻。
- JSON 可选字段与 schedule 类型的往返、旧 U2 磁盘迁移回归、Health 导入门槛保持通过；不改变同步队列合同。

## 需求对应

U3/R4：动作搜索/肌群/器械筛选、自定义编辑归档、来源详情、模板目标/复制/重排/重复项目、周安排、单次改期和当天开始均已实现。22 条自有目录符合本单元允许的少量条目交付；约 100 条和专业内容复核仍为发布内容门槛。

训练开始与返回为 U3 可用结果，逐组执行/计时/完成统计为 U4；不把后续能力的预留字段宣称为已交付。无需远程接口，不增加第三方依赖，未移植研究仓库代码。
