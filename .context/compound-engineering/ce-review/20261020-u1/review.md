# U1 顺序复查

范围：`app/ios/Leanora`、单元与 UI 测试、工程和配置；不包含研究副本和构建产物。用户只授权 U1，U2–U8 未实现属于既定范围。

方式：依照用户 AGENTS 在主线程顺序执行 ce:review 的复查视角，未派生子代理。工作区根目录无 Git 仓库，因此按全部新增交付文件复查，不虚构提交差异。

## 已处理

- 正确性：通知 refresh/request 竞态已用操作版本解决；健康写入授权返回前台后刷新；读取授权没有被错误推断。
- 可操作性：长标题随表单滚动、子页返回导航显式可用；数字键盘可清除与收起，输入栏只在聚焦时通过安全区挂载一次，避免键盘工具栏初始布局告警。
- 权限：仅用户主动触发请求；请求时锁定选择；空范围或不可用时不调用系统；不记录个人健康内容。
- 测试：偏好测试使用真实 UserDefaults；mock 用于可复现的异常边界；另以真实系统授权页面验证调用链，不把 mock 结果当作设备证明。
- 维护性：没有业务数据库、同步队列、账号或内容库的提前实现；授权协议由系统、单元与 UI 测试适配器共同使用。
- 项目规则：使用独立代码与原创资源；依赖与内容角色有来源字段；未引用 AGPL 研究副本；未提交或推送代码。

## 观察与限制

- Agent-native：本 App 没有内置 Agent/LLM；U1 只有导航和偏好等低优先级动作，可通过无障碍语义和 UI 自动化操作。没有据此扩展成 Agent 服务或开放健康数据接口。系统同意弹窗是平台权限流程。
- 既有经验：工作区没有 `docs/solutions/` 或 critical-patterns 文件可复用。
- 设备门槛：本机有开发身份，但工程未选择 Developer Team，未连接物理 iPhone。U1 的真机、VoiceOver 与最低系统验收仍待完成，当前不能放行商店发布。

详细测试结果与截图见 `app/docs/qa/phase-one-verification.md`；最终联跑结果以该记录及对应 xcresult 为准。
