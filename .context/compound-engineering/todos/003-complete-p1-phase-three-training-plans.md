# 阶段 3：动作库、模板与周安排

## Problem Statement
按用户授权实现 U3 全部功能和验证。

## Findings
U2 数据基础可用；U3 需保存单次改期，与每周安排分离，并在开始时冻结计划目标和动作快照。

## Proposed Solutions
原创随包动作目录、原生搜索/筛选与编辑；通过持久化 actor 处理模板复制、归档、周安排、单次改期与开始训练。

## Recommended Action
按 U3 执行，主线程顺序开发/审查，不使用子代理。保留 U1 的真机门槛。

## Acceptance Criteria
- [x] 本地动作搜索、肌群/器械筛选、来源详情、自定义编辑与归档
- [x] 模板新建/编辑/复制/重排/重复动作，目标组次数负重休息配置
- [x] 周安排、单次改期互不覆盖，当天可开始训练
- [x] 空模板/归档动作开始保护，重复点击不重复创建，活动训练可返回
- [x] 已开始快照不随模板/动作修改，磁盘重开与备份兼容
- [x] 单元/UI/构建验证、截图与报告，顺序代码审查
