# Leanora Fitness 1.2：训练效率与原创内容

本轮版本计划见 [2026-10-29 计划](../../docs/plans/2026-10-29-001-feat-training-workflow-content-plan.md)。参考训记公开功能与已有静态开发报告，独立实现交互与数据规则；未导入训记内容。

## 用户流程

- 训练首页直接开始自由训练，或返回唯一进行中/暂停的训练。无需先建模板。训练中可改名、添加动作、通过动作标题菜单调整顺序或确认移除动作；变化只影响本次快照。
- 动作选择器保留搜索、器械、肌群、类型与难度筛选，增加“全部 / 收藏 / 最近”。详情可收藏，列表也支持滑动收藏。最近最多 20 个，仅依据未删除、已完成训练中的完成组推导。
- 训练组附近显示最近一次合适历史的日期和实际值，按组类型对应。点击“沿用上次”只填入尚未完成且未开始计时的组，不带入主观强度、完成时间或计时状态。
- 历史列表“再练一次”从已完成组创建独立训练。所有嵌套 ID 重建、完成标记和时间清空，不保留原日历安排；已有活动训练时返回它。原历史保持。
- 完成后进入训练历史，可“存为新模板”；若原模板修订仍匹配，也可明确选择“更新原模板”。两者先打开未保存草稿，只有点击编辑器保存才落盘。草稿只提取完成正式组，组数按实际、目标取首个完成正式组；原模板名称、备注与周安排在更新时保留。保存再次校验修订，禁止覆盖更新后的模板。

训练顶部将名称、状态、归属日期和有效时长集中展示，减少进入组记录前的滚动；名称输入支持清空后重填。所有新入口保留文本标签和原生大字号布局。

## 原创离线内容

`Resources/Catalog/training-content.json` 是 Leanora 原创、MIT 许可的本地资源：

| 计划 | 模板数 |
| --- | ---: |
| 全身基础 A/B | 2 |
| 哑铃全身 A/B | 2 |
| 徒手基础 A/B | 2 |
| 推、拉、腿 | 3 |

预览不会写库；“采用”在一个事务中保存全部模板和所需目录动作，失败整体回滚。重复采用分配独立 ID 与可区分的名称，不写每周安排，不覆盖用户模板。不预设负重，用户可编辑后安排训练日。

8 篇原创指南解释自由训练、目标与实际、组类型、休息与暂停计时、主观强度、容量统计、复用和模板、备份及 Apple Health。新增计划和指南以中文提供。引用现有常用动作及已许可图片，图片的独立许可不变。

## 数据与健康边界

收藏使用可选 `Exercise.isFavorite`：旧 JSON 缺失时未收藏，取消时存 nil；沿用原备份版本与 SwiftData 实体。旧目录 ID、训练历史快照、食品与健康合同保持兼容。

`AppModelActor` 仍是唯一写入端。自由训练、新增动作、再练和范例采用都使用现有事务、修订与容量校验。原始完成组不因参考填入而改变。上次参考要求历史结束早于当前训练开始；排除当前、删除、未完成和计量变化记录，同一动作优先按模板项目匹配，否则按出现顺序对应。

开始和修改活动训练不产生 Health 写入任务；完成训练才进入既有健康队列。保存模板、收藏和阅读内容不请求新的健康权限。没有内容下载接口、账号、追踪或新增远端数据传输。

## 验证范围

核心规则由 `WorkoutWorkflowTests`、`TrainingContentTests` 及既有数据/备份/Health 回归覆盖。原生流程由 `TrainingWorkflowTests` 验证，并回归模板、动作指导和训练恢复。具体结果、截图与发行凭据见本轮 QA 记录。模拟器检查不等于真机 Health、通知锁屏送达或内容专业审核。
