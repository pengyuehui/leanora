# Leanora Fitness 1.3 验证

完整计划见 [版本计划](../../../../docs/plans/2026-10-30-001-feat-nutrition-workflow-content-plan.md)，逐用例结果、日志和结果包索引见 [verification.json](verification.json)。本轮按定向批次合并最终通过结果，不宣称早期失败的整批测试全部通过。

基础测试共 138 项，0 失败、2 项原有 opt-in 容量测试跳过；新增 15 项覆盖目录兼容/官方来源、收藏与最近、组合快照/缩放、真实磁盘重开、备份 v1/v2、批次幂等及 Health 意图事务。对 500 条食品的全部营养与份量逐项比较官方 ZIP，旧 300 条哈希保持一致，结果见 [食品校验](../../food-catalog-verification.json)。

原生范围为 15 个功能场景及 1 个截图制作场景，具体最终通过项以 JSON 为准。新增流程覆盖收藏、150 g 快捷输入、明确沿用上次、从早餐生成组合、改名保存、重启恢复、半份午餐及 585 kcal 汇总；另验证原创搭配预览/取消不写、采用保存和离线指南；深色 AX XXXL 验证组合快速热量、条目数量修改、0 份拦截、半份记录及未知营养。旧饮食、自定义食物、身体测量、备份原生文件选择器、错误导入、启动恢复、训练历史修订、计时及系统通知定向回归。

验证发现并修复两项产品问题：组合名称与备注共用焦点导致清空后输入不稳定，现使用独立字段焦点；非法份数时错误位于长表单底部且键盘仍展开，现确认时收起键盘并在份数旁显示错误。完整深色大字号流程在最终产品代码上通过。后续调整仅涉及测试帮助器，没有改变归档中的应用代码。

早期失败另包含测试工具兼容问题：冷启动等待不足、LabeledContent 被当作 StaticText、Duo 懒加载列表的滚动几何和表单输入区域、返回后错误地期待历史列表，以及 TimelineView 静态文本无法生成点击点。修正等待和控件查询，静态文本按可见范围验证，保留实际值、重启与结果断言。原始失败日志和 xcresult 保留在被忽略的 `app/build/`；测试进程诊断收集未完成的结果包不作为最终通过凭据。

仓库中的 `v13-*.png`、`u4-*.png` 均为通过用例的未改动原图，记录为隔离测试库示例。没有植入真实用户饮食、Health 样本或虚构同步成功。商店 7 张源图与 14 张展示图的来源和哈希见 [截图说明](../../../store/screenshot-test-summary.json)，素材本地校验见 [素材验证](../../../store/verification.json)。

发行快照保留开始本轮前的未提交本地化修改，不将其打入正式包。最终签名、五份目录、1765 张图、许可、HealthKit 权限、Release 无夹具及提交源码关联以发行审计为准。隐私与支持页 HTTPS 200 的核验见 [公开页面](public-websites.json)。

本轮不宣称完成物理设备 HealthKit、最低 iOS 18、真实 VoiceOver、锁屏通知或营养专业审定。新增搭配和指南为中文，部分食品名称/来源单位仍为英文。JSON 格式 2 需要 1.3 或更高兼容版本恢复，继续读取旧格式 1。
