# Leanora Fitness 1.2 验证记录

日期：2026-10-29 至 10-30。功能范围见 [1.2 训练流程](../../training-workflow-1.2.md)；逐项结果见 [verification.json](verification.json)。

本轮实现自由训练、训练中动作管理、上次表现、历史再练、完成正式组回用模板、收藏/最近动作，以及 4 套原创计划、9 个可编辑模板和 8 篇离线指南。模板更新先打开草稿再保存，历史与原计划快照分离。

## 结果与范围

- Foundation：123 项，0 失败，2 项原有容量测试按默认设置跳过。覆盖本次新增的 14 项训练工作流测试和 5 项内容测试，以及既有持久化、恢复、备份与 Health 队列回归。
- 原生 UI：10 个功能场景及 1 个商店截图制作场景，经多批定向复测均取得通过结果。不是把包含失败的早期批次称为一次全绿测试；每个通过用例的来源及 `.xcresult` 路径保存在 JSON 中。
- 场景包括自由开始、逐组完成、存模板、历史再练、沿用上次保护已完成组、重启恢复；收藏与搜索、范例预览/采用/开始、指南；超大字号深色模式下改名/排序/计时/暂停/移除；动作指导、模板复制、周计划启动、计时恢复及历史更正。
- 图片目录校验通过：882 个动作、1765 张图片。发行 IPA 深度严格验签通过，Apple Distribution 团队为 `8ZP3NMT2A8`，HealthKit 与 background-delivery 均开启，非开发调试权限；四份目录 JSON、全部图片哈希和三个许可文件正确，Release 无测试夹具。
- `Localizable.xcstrings` 为开始本轮前已存在的未提交修改；所有构建关闭字符串提取，逐字节与保留副本一致，不包含在本轮提交中。

## 失败与修正

早期基础测试将内存中带更高小数精度的 Date 与编码后记录直接比较；改为比较落盘前后的规范记录，验证失败回滚和历史不变。

原生检查发现首次打开改名窗口时，输入绑定已更新，清空按钮与保存条件却可能仍按空值渲染。将改名表单独立为带初始草稿状态的 `WorkoutNameEditor`，后续最大字号完整流程通过。

Duo 外屏会按需建立长列表行，且执行页有固定完成栏；旧测试的整页快速滑动与“存在即可点击”会越过目标或点击遮挡的完成栏。改为核对可见边界、小幅滚动并等待引导准备；系统确认弹窗的父子按钮可能共享标识，明确选择首个匹配并验证动作后的状态。业务断言保留，未跳过失败 UI 用例。原始失败日志与结果包仍在被忽略的 `app/build/` 中。
