# 记录主流程与视觉调整

2026-10-21。参考依据：[训记官方 App Store 展示](https://apps.apple.com/cn/app/id1464915553) 的计划、训练和饮食截屏，以及本项目先前的 [功能研究](../../analysis/训记与薄荷-开发参考.md)。展示图可证明视觉与控件组织，不能替代完整真机流程验证。未复制图片、图标、源码、文案或专有库。

## 视觉方向

使用系统浅灰/白底、深色文字和蓝色操作强调，保持深色模式原生对比。大标题负责页面名称，数字使用等宽数字；移除首页的大段品牌口号。卡片用于今日训练与营养这两个完整任务，普通资料维持列表。字体随系统变化，窄屏与大字体采用纵向回退，不把健康数值强行缩成微小字号。

## 页面顺序

- 今天：日期 → 正在训练/今日安排/选择模板（唯一主要动作）→ 已知热量与三种营养素 → 身体记录/趋势。正在训练不会被新模板覆盖。
- 训练：进行中入口 → 动作库/周计划/历史 → 今日安排 → 个人模板。开始前查看计划，执行时保存实际值，历史不会随模板更改。
- 执行：训练状态与有效时长 → 动作目标 → 对齐的组号、实际值、编辑与完成 → 添加组/备注。完成组后出现休息；底部保留结束入口。已完成组有勾选符号与颜色双重反馈。
- 饮食：日记日期与前后日切换 → 已知能量/宏量营养素 → 快捷热量/复制 → 餐次明细与新增。搜索优先显示最近使用的食物，来源/筛选详情收进披露区；自定义资料始终可用。
- 我的：单位/提醒 → Health 读写、同步状态和来源 → 备份/导入/CSV/三个独立清理 → 隐私。

## 必须保留的语义

营养未知不能显示成零；部分合计说明保留。完成组之前缺少实际值会提示，不能将目标直接算成完成。计时按保存时刻恢复，不依赖页面每秒保持运行。健康摘要与本机餐次分开；设置完成不是“已同步”。导入成功后显示反馈，并保留恢复门槛。

原生控件保留 VoiceOver 名称、顺序、44pt 触摸区域及 Dynamic Type。XCTest 检查真实 iOS 页面与对比/裁切，VoiceOver 听读、物理小屏和锁屏仍按发布矩阵验收。
